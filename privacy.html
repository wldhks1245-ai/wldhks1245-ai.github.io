  1. 수집하는 정보: TikTok 로그인 시 TikTok이 제공하는 기본 프로필 정보(open id, 표시 이름)와 접근 토큰만 사용합니다.
  2. 이용 목적: 운영자 본인 계정으로 영상 업로드(video.upload)를 하기 위해서만 사용합니다.

  4. 삭제: TikTok 앱 설정에서 언제든 권한을 해제할 수 있고, 해제 시 토큰은 더 이상 사용되지 않습니다.
  1. Data: only the basic profile info TikTok returns at login (open id, display name) and the access token.
  2. Purpose: uploading the operator's own videos to their own account (video.upload). Nothing else.
  3. Storage: tokens are stored only on the operator's own computer and are never shared or sold.
  4. Removal: access can be revoked anytime in TikTok settings; revoked tokens are no longer used.
